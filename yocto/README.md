# Yocto

Kas config and the `meta-pb2` layer live here. The image is built with kas-container from the repo root. Nothing in this directory is flashed to the board.

```
wget -O kas-container https://raw.githubusercontent.com/siemens/kas/5.5/kas-container
chmod +x kas-container
KAS_BUILD_DIR=yocto/build KAS_CONTAINER_ENGINE=podman ./kas-container build yocto/kas/pb2-poky.yml
```

- `kas/pb2-poky.yml` — includes TI's poky-wrynose kas file, machine `pocketbeagle2`, distro `poky`, target `pb2-demo-image`
- `layers/meta-pb2` — recipes that compile the Linux demo, the Zephyr M4 firmware, and both PRU firmwares
- `sources/`, `downloads/`, `build/` — generated by kas-container, not committed
